# Paseo Essentials

ChatGPT and OpenCode Go limits, token history from Codex/Pi/OpenCode,
workspace usage, and CLI/model updates.

Requires Paseo **0.9.2+** on the app and daemon; Node **22.13+** for OpenCode history.
Quota lookup uses Codex's ChatGPT login or OpenCode Go's connected account.

Enable **Settings → Plugins → Enable plugins**, then add this **Plugin source**:

```text
https://github.com/josephjs1dev/paseo-plugins.git:essentials
```
